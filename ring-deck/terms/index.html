Ring Deck terms

Ring Deck is a Stream Deck plugin I built for my own Mac. Nobody else signs in to it, and it isn't sold or offered to anyone.

What it is. It shows the numbers Oura already has for me. It isn't medical advice, and a number on a key is only as fresh as the last time my phone synced with the Oura app.

No promises. It's a personal project, so it comes as is. If Oura changes its API, it may stop working until I fix it.

Oura's rules still apply. Ring Deck uses Oura's API under the Oura API Agreement. Oura is a trademark of Oura Health Oy, and Ring Deck isn't made or endorsed by Oura.

Questions. Open an issue on github.com/malikacodes.
